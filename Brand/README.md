# Brand

A place for logo and icon artwork used by Home Assistant and HACS.

This folder is intentionally empty. No manufacturer logos are included here, because the
Dolby and Doremi marks are trademarks of their owners and this project is not affiliated
with them.

If you want icons in your own installation, or you hold the rights to artwork you would
like to contribute, drop the files here:

| File | Size | Used for |
|---|---|---|
| `icon.png` | 256×256 | Integration icon |
| `icon@2x.png` | 512×512 | High-DPI integration icon |
| `logo.png` | max 256 high | Brand logo shown in the integration page |
| `logo@2x.png` | max 512 high | High-DPI brand logo |

PNG with transparency, trimmed to the artwork with no padding. The same layout is used by
the official [home-assistant/brands](https://github.com/home-assistant/brands) repository,
so anything placed here can be submitted upstream unchanged.
