# Brand

Icon and logo artwork for this integration, as shown by Home Assistant and HACS.

The artwork here is a generic cinema-server mark drawn for this project: a server chassis
with a film strip and a play button. It deliberately contains no manufacturer logo, because
the Dolby and Doremi marks are trademarks of their owners and this project is not affiliated
with them. The copy Home Assistant actually loads lives in
`custom_components/dolby_ims3000/brand/`.

You are free to replace these files with your own artwork, or with official logos if you hold
the rights to use them. Keep the file names and sizes:

| File | Size | Used for |
|---|---|---|
| `icon.png` | 256×256 | Integration icon |
| `icon@2x.png` | 512×512 | High-DPI integration icon |
| `logo.png` | 128 high | Logo on the integration page |
| `logo@2x.png` | 256 high | High-DPI logo |
| `dark_logo.png` | 128 high | Logo in dark mode |
| `dark_logo@2x.png` | 256 high | High-DPI logo in dark mode |

PNG with transparency, trimmed to the artwork. The same layout is used by the official
[home-assistant/brands](https://github.com/home-assistant/brands) repository.
